# Changelog

## 2026-08-01

- TipTap 颜色与代码增强：文字/背景色支持预设色 + SV/色相色盘与十六进制；修复色盘被编辑区盖住导致清除按钮失效/指针变 I 形的层叠问题；行内代码对比度加强；代码块改为可配置语言、行号、换行、字号与缩进的窗口式组件（含复制）。
- 丰富 TipTap 工具栏：段落/字号、上下标、文字色与高亮、对齐、行内代码等；表格改为 Word 式行列选择器，并修复选中单元格高亮盖住全文导致删行删列困难的问题，表格内提供浮动行列操作条。
- 文章编辑页汉化并打磨：TipTap 正文列居中、工具栏图标放大；元数据改为中文标签；封面改为与正文相同的链接/上传弹窗；顶栏按钮与状态文案统一中文，样式更顺滑。
- 编辑器插入图片改为双 Tab 弹窗（图片链接 / 上传图片），支持拖拽上传与替代文本；新增后台「存储」Tab 与存储策略配置页（本地/云存储雏形，可添加与编辑策略）。

## 2026-07-31

- 补齐后台内容编辑闭环：文章管理新增列表/筛选/编辑/删除，编辑器可按 ID 加载已有文章；观测台编辑改为拉取详情，避免正文被清空。
- 将媒体、评论、用户、插件、主题及新增「构建中」从占位页升级为可本地增删改的雏形工作台（localStorage），便于后续接真实 API。
- 彻底重做 `/notes` 笔记列表为杂志级阅读归档：独立视觉语言与氛围动效，Hero 统计、粘性搜索/筛选/视图切换、Featured 大卡、Mosaic 不对称网格与 Stream 列表，并支持加载更多。
- 重做 `/notes` 笔记列表为编辑式博客版式：对齐其他 Tab 的 `SectionIntro`，首篇大图 Featured + 下方细线流式列表，衬线标题、置顶/阅读量元信息，并修复无封面时的空白栅格问题。
- 重新设计文章详情页为沉浸式月面阅读体验：新增全屏研究站 Hero、滚动视差与阅读进度、自动章节目录、字号/复制/分享/收藏工具、宽幅正文媒体与完整富文本排版，并支持响应式和减少动态效果偏好。
- 将文章详情页调整为阅读优先的博客版式：重构居中标题区、中文日期与阅读时长、宽幅封面、窄正文阅读列和轻量页尾统计，并完善移动端排版。
- 将 `/notes` 从日志时间线改为常规博客笔记页：使用居中页头、阅读型文章卡片、发布日期与阅读时长元信息，并支持文章封面和移动端单列布局。
- 重写首页 `LunarOrbit`：大尺寸墨绿月牙为稳定核心，三层规则椭圆轨道统一环绕形成引力场；提高轨道可见度与节点对角平衡，去掉背景光斑与随机断线。
- 修复 `/notes` 笔记列表有接口数据但不显示的问题：将首屏 `whileInView` 改为 `animate`，避免内容卡在 `opacity: 0`；笔记页改为服务端拉取公开文章后传入列表组件。
