# 前端设计规范

- 前端使用 pnpm 管理依赖。
- 样式优先复用 `frontend/src/app/globals.css` 中的颜色变量，避免在组件内重复定义颜色。
- 图标优先使用项目已安装的 `lucide-react`，并明确尺寸。
- 首页以内容阅读为主，使用清晰的标题层级、充足留白、细分隔线和克制阴影。
- 文章详情采用杂志三栏版式：左互动栏、中阅读列、右目录/相关文章；页头含面包屑、衬线标题与规格卡，正文 h2 自动编号。
- 浅色主题使用暖白页面、柔白卡片和低饱和抬升表面形成三层层级；避免大面积纯白与纯灰并置。正文使用墨绿色系，苔绿只承担主要操作、当前状态和少量关键标记。
- 卡片默认可使用低透明度阴影建立轻微承托，悬停时再增强边框或阴影；同一组件不同时叠加强色、粗边框和重阴影。
- 动效服务于层级和状态表达，不改变内容结构；必须支持 `prefers-reduced-motion`，并避免造成布局偏移。
- 内部链接使用 Next.js `Link`，图片保留稳定尺寸，交互元素必须有清晰的焦点状态。
