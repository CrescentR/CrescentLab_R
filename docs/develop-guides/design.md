# 前端设计规范

- 前端使用 pnpm 管理依赖。
- 样式优先复用 `frontend/src/app/globals.css` 中的颜色变量，避免在组件内重复定义颜色。
- 图标优先使用项目已安装的 `lucide-react`，并明确尺寸。
- 公开站统一参考 Crescent Index HTML 稿：黑色 64px 网格基底、纸白文字、荧光黄绿强调色；信号橙用于状态，钴蓝与纸白叠层用于首页海报。首页、动态、项目、笔记、关于、项目详情和文章详情共用 `frontend/src/app/lab-home.css` 的公开站变量、导航、内容宽度与间距。
- 公开信息架构使用“动态 / 项目 / 笔记”三个内容栏目；动态内部收纳“近期进展”和“过程记录”，不在公开侧使用实验室、实验观测或正在构建等概念。
- 文章详情在公共刊物体系内承担长文阅读：深色全屏封面、错位图像、纸张正文舞台、控制台阅读工具、章节索引与讨论区共同形成阅读节奏。
- 公开内容卡片采用深色表面、1px 细边框与 8px 圆角，交互按钮与导航使用 6px 圆角；管理端与登录页保留原有表单体系。
- 用字体层级、留白、网格和小面积强调色区分信息；避免大面积彩色卡片、粗边框和硬阴影反复竞争。错位色块阴影集中用于首页海报，真实内容封面保留原色。
- 高对比色块必须设置明确的前景色，不依赖祖先元素继承：荧光黄、信号橙和纸张白使用深色文字，钴蓝使用纸张白文字；正文和关键元信息不得通过低透明度削弱到难以阅读。
- 用户上传的真实封面保持原始色彩，不强制增艳、套色或使用混合模式；带封面的内容卡片使用中性纸张色承载文字，高对比色块保留给无封面占位和小面积状态强调，避免封面主色与固定强调色竞争。
- 公开站顶部导航在所有页面保持一致，当前项使用荧光黄绿底与深色文字；普通态、悬停态与当前态必须能被清楚区分，手机视口保留完整导航入口。
- 动效服务于层级和状态表达，不改变内容结构；必须支持 `prefers-reduced-motion`，并避免造成布局偏移。
- 内部链接使用 Next.js `Link`，图片保留稳定尺寸，交互元素必须有清晰的焦点状态。
