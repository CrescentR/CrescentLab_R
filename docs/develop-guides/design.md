# 前端设计规范

- 使用 pnpm 管理依赖，复用公开站 `globals.css` 中纸张／墨色／强调色变量；图标使用已有的 lucide-react。
- 公开站以用户提供的纸张刊物设计稿为准：首页、笔记、文章、项目、项目详情和关于共用页头、页脚、内容宽度、字体和日夜主题。禁止继续混用旧深色网格、蓝橙海报或大色块产品卡片。
- 默认暖纸 `#f4f1ea`、黑墨 `#1a1a18`；夜间纸色 `#0f100e`、文字 `#f1eee4`。荧光绿 `#d9ff43` 用于划重点，链接使用钴蓝 `#3442e0`（夜间 `#8e98ff`），放弃与修订提醒使用橙色 `#ff5b35`。
- 中文标题使用 Noto Serif SC 宋体；英文标题使用 Instrument Serif 斜体；日期、编号和分类使用 JetBrains Mono；界面及正文以清晰易读为先。
- 页头使用实时月相与今夜名称，导航只保留笔记／项目／关于；移动端将导航置于品牌行下方。品牌返回首页。
- 首页为最新长文与札记双栏，下设长文索引、合集及项目；小面积边框与分隔线形成刊物层级。
- 笔记按月份混排长文与札记，动态入口重定向到笔记；统计基于真实公开内容，不填充示例数字。
- 项目月相由明确字段决定：新月＝研究，上弦＝构建，满月＝上线，下弦＝收尾；归档／放弃集中到 Waning 并写明原因，不从发布状态猜测阶段。
- 文章采用纸张阅读布局：中文大标题、正文左侧目录、真实封面、文末修订记录及相邻文章／合集导航；移动端改为单列，阅读工具仍可操作。
- 真实封面保持原色；没有封面、关联或修订数据时不伪造内容。
- 首页封面鼠标预览只对支持 hover 且未启用减少动画的设备开启；所有装饰动效服从 prefers-reduced-motion。阅读进度作为状态指示保留。
- 内部链接使用 Next.js Link；按钮、搜索与筛选可键盘操作，焦点清晰；深浅主题都应有足够对比度。
- 管理后台保留原有布局，只补充本次新增字段的录入。
