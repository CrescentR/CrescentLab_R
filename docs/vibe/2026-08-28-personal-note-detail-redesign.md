# 笔记详情页「个人月相手记」改版

日期：2026-08-29

## 目标

把笔记详情页从常见的三栏文章模板改成具有 Crescent Lab 个人博客气质的长文页面。页面仍以阅读为主，不新增文章字段、不改变正文数据与评论流程。

## 已否决方向

第一版「浅色网格 + 独立月相印章 + 横向元信息带」已否决。它的问题是靠空白建立形式感，月相装饰与文章内容割裂，短标题时尤其像未完成的线框稿；全局导航也仍是通用产品站 Tab。

## 最终设计方向

- **墨色刊头**：以墨绿色高对比刊头承载标题、摘要、月牙与元信息，避免用空白代替构图。
- **个人站导航**：文章详情页导航显示栏目序号、双行品牌签名和明确当前项，取消普通胶囊 Tab 的产品站气质。
- **一体化月牙**：月牙进入刊头信息区，作为站点签名而不是悬空装饰组件。
- **刊物式正文**：首段加强、章节编号进入标题排版、正文列保持适合长读的宽度，代码、引用、表格与图片继续完整支持。
- **封面是文章插图**：保留原图完整比例与留白，增加轻量图注，不让封面成为压住正文的大型素材预览框。
- **个人署名式收束**：文末以「写于 Crescent Lab」结束，不虚构作者姓名或个人资料。
- **轻量工具与目录**：桌面端保留两侧阅读辅助；移动端将阅读工具变为可触控的横向操作带，不显示空目录。
