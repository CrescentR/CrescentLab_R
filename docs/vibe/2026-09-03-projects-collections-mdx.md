# 项目详情、MDX 与内容集合

## 目标

- 让项目拥有独立的公开详情页，展示完整 README 式内容、技术栈、仓库和演示入口。
- 项目正文支持 Markdown/MDX，MDX 组件通过前台显式白名单渲染。
- 文章正文为空 HTML 时从已保存的 Markdown 源文档重新生成，避免只显示标题。
- 文章 Contents 只收录一级标题（`h1`）。
- 内容集合是内容的组织维度，与标签保持独立；当前仓库已有文章分类字段，后续集合管理按同一内容组织模块扩展。

## 验收清单

- [x] 项目公开列表与 `/projects/:slug` 详情接口。
- [x] 项目保存 `content_md` 与 `source_format`，支持 `mdx`。
- [x] 项目详情使用 README 式双栏布局，并提供受控 `Callout` 组件。
- [x] 文章正文空 HTML 时从 Markdown 恢复渲染。
- [x] Contents 和滚动监听仅使用 `h1`。
- [x] 复用现有文章分类表作为内容集合，补充集合 CRUD 接口与文章关联 UI。
