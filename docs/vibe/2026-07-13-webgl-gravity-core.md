# WebGL 引力共振核心

## 目标

将首页 Hero 中原本以自动旋转为主的 WebGL 月牙升级为可直接互动的视觉核心，使交互反馈发生在 3D 场景内部，不移动外围 Hero 容器。

## 范围

- 桌面端精细指针环境继续使用 WebGL 核心。
- 悬停时提高月牙辉光，并加速轨道、粒子场与探测点。
- 月牙使用带厚度和倒角的挤出几何体，正面与侧面使用不同材质，并保持可观察到侧壁的基础倾角。
- 使用冷色主光、双色点光和轻微暖色补光建立曲面高光与侧面阴影。
- 按住拖动时改变 3D 月牙的旋转和少量位置偏移。
- 松开后通过弹簧动画晃动回正，并释放一圈扩散能量波。
- 减少动态偏好和不支持当前 WebGL 模式的设备继续使用静态月牙。
- 不修改 Hero 布局、首页内容结构和导航行为。

## 验收 Checklist

- [x] 拖动 WebGL 月牙时，3D 姿态跟随指针变化。
- [x] 待机、自动运动和拖动状态下都能辨认月牙的厚度与倒角。
- [x] 正面高光、侧面暗部和拖动透视变化形成稳定的体积层次。
- [x] 松开后月牙回弹，并在稳定后回到原有运行状态。
- [x] 悬停、拖动和释放具有不同且连续的视觉反馈。
- [x] 静态降级模式不显示不可用的拖动提示。
- [x] `pnpm typecheck`、`pnpm lint` 和 `pnpm build` 通过。
- [x] 生产页面返回 HTTP 200，并通过真实浏览器自动拖拽验证。
