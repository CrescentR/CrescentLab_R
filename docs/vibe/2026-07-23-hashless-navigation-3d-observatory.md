# 无 Hash 导航与可滑动实验观测台

> 日期：2026-07-23
> 范围：前台首页导航、Hero 快捷入口、实验观测台

## 目标

首页区块导航不再通过 URL Hash 工作，点击后保持当前地址不变并滚动到对应内容。实验观测台不接管页面纵向滚动，用户可主动拖拽卡片、点击索引或使用左右方向键查看三条观测内容；卡片在拖动和切换时呈现柔软回弹与果冻形变。

## 交互规则

- 顶部品牌、顶部导航和 Hero 快捷入口使用按钮触发区块滚动。
- 页面区块保留现有 `id`，仅作为程序内部的精确滚动目标。
- 页面经过实验观测台时保持正常纵向滚动，不固定视口，也不消费纵向滚轮行程。
- 三张实验卡片在同一舞台内沿 Z 轴叠放。
- 横向拖拽超过切换距离后，当前卡片离场，相邻卡片从后方进入。
- 拖拽过程中当前卡片产生非对称圆角和拉伸压缩，相邻卡片同步前移；释放后使用弹簧动效回弹。
- 点击索引或使用左右方向键可直接切换卡片。
- 观测索引和进度条与当前卡片同步。
- 触摸设备保留页面纵向手势，横向滑动用于切换卡片。
- 启用减少动态效果时保留切换能力，但停用拖拽和弹簧过渡。

## 验收标准

- 点击首页内部导航后，`pathname` 和查询参数保持不变，地址栏不增加 Hash。
- 首页、正在构建、实验、项目、笔记和关于区块均能通过现有入口抵达。
- 实验观测台不再使用左侧索引与右侧内容的横向双栏。
- 页面滚动经过实验观测台时不被固定或拦截。
- 桌面端可拖拽、点击索引或使用方向键切换三张卡片。
- 触摸设备可横向滑动卡片，且卡片上的纵向手势仍可滚动页面。
- 拖动与切换具有清晰的果冻形变、相邻卡片响应和弹簧回弹。
- 减少动态效果模式可通过索引和方向键切换卡片，不播放拖拽与弹簧动效。
- 不修改实验数据、首页区块顺序、文章接口或项目弹窗。
