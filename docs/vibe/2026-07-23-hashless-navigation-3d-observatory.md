# 无 Hash 导航与 3D 实验观测台

> 日期：2026-07-23
> 范围：前台首页导航、Hero 快捷入口、实验观测台

## 目标

首页区块导航不再通过 URL Hash 工作，点击后保持当前地址不变并滚动到对应内容。实验观测台由横向双栏切换改为纵深叠放的 3D 卡片，用户继续向下滚动时依次查看三条观测内容，换页节奏接近 PPT 的卡片退场与进入动画。

## 交互规则

- 顶部品牌、顶部导航和 Hero 快捷入口使用按钮触发区块滚动。
- 页面区块保留现有 `id`，仅作为程序内部的精确滚动目标。
- 桌面端三张实验卡片在同一舞台内沿 Z 轴叠放。
- 向下滚动时，当前卡片向上翻转退场，下一张从后方进入并成为主卡片。
- 观测索引和进度条与当前卡片同步。
- 980px 以下、视口高度不足 720px 或启用减少动态效果时，三张卡片按正常文档流纵向展示，不固定页面。

## 验收标准

- 点击首页内部导航后，`pathname` 和查询参数保持不变，地址栏不增加 Hash。
- 首页、正在构建、实验、项目、笔记和关于区块均能通过现有入口抵达。
- 实验观测台不再使用左侧索引与右侧内容的横向双栏。
- 桌面滚动可依次激活三张 3D 卡片，且滚动离开观测台后页面继续正常向下。
- 移动端和减少动态效果模式可直接阅读全部三张卡片。
- 不修改实验数据、首页区块顺序、文章接口或项目弹窗。
