# 多存储策略与内容上传

日期：2026-08-01

## 目标

后台可配置并管理多种存储策略，选择唯一默认策略；内容编辑器上传的图片和附件使用该默认策略，生成可长期访问的站内文件地址。

## 范围

- AWS S3
- Cloudflare R2
- S3 兼容存储（含 MinIO 等）
- 阿里云 OSS
- 腾讯云 COS
- 七牛云 Kodo
- OneDrive
  - 管理员委托 OAuth 授权
  - Tenant ID、Client ID、Client Secret 应用凭据

不增加上述列表之外的存储提供商。

## 验收标准

- 管理员可以创建、编辑、连接测试、启用、停用和删除策略。
- 任意时刻最多一个启用策略为默认策略。
- 策略列表和详情接口不返回 Secret、Access Token 或 Refresh Token。
- OneDrive 委托授权支持 OAuth 回调与 Token 自动刷新；应用凭据支持自动获取 Token。
- 内容编辑器可以上传图片并插入图片节点，也可以上传附件并插入下载链接。
- 上传使用当前默认策略；没有默认策略时返回明确错误。
- 文件使用稳定的站内 /f/{id} 地址访问，私有 Bucket 不依赖短期签名 URL。
- 写操作接口统一使用 POST，不使用 PUT 或 DELETE。
- 单文件最大 20MB。
