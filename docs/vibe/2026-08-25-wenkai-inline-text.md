# 文楷行内文字样式

日期：2026-08-25

## 目标

允许作者在 CMS 富文本编辑器中为选中的诗词、随笔、手账句子或摘录应用霞鹜文楷，同时保持普通技术文章和项目介绍的默认字体不变。

## 范围与验收标准

- 编辑器工具栏提供“文楷”按钮，可对当前选区切换文楷样式。
- 文楷样式以 `<span class="wenkai-text">` 保存，不写入具体的内联字体样式。
- 后端 HTML 清洗保留 `wenkai-text`，并继续移除未允许的类名与脚本。
- CMS 编辑器和文章详情使用相同的文楷字体栈。
- 字体文件预留在 `frontend/public/fonts/lxgw-wenkai/`，缺失时使用系统楷体和正文衬线字体回退。
- 不增加访客字体选择器，不改变未标注文楷的现有内容。
