# 后台字体可读性优化

> 日期：2026-07-23
> 范围：后台公共框架、表单、状态信息与文章编辑器

## 目标

在不改变后台布局、功能逻辑和字段尺寸的前提下，解决后台界面字体拥挤、字号偏小的问题，建立一致且清晰的后台字体层级。

## 验收标准

- 后台 UI 使用鸿蒙黑体优先的无衬线字体栈。
- 原有 10px、11px 辅助文字统一为 12px。
- 原有 12px 标签文字提升为 13px。
- 原有 14px 正文与操作文字提升为 15px。
- 文章写作区正文使用 16px，代码内容继续使用等宽字体。
- 不修改后台导航结构、编辑器功能、表单尺寸或业务逻辑。
- 桌面视口下侧栏、顶部栏和编辑器无横向溢出。

## Checklist

- [x] 后台字体作用域仅影响 `/admin`。
- [x] 侧栏与顶部栏文字层级清晰。
- [x] 元数据字段和状态文字可读。
- [x] 编辑器正文和占位文字达到 16px。
- [x] 类型检查、相关 Lint 与浏览器验证通过。
