# 首页参考稿视觉对齐记录

> 日期：2026-07-09
> 范围：前台首页 `/`

## 目标

根据参考截图，将当前首页从偏卡片化的 Soft UI 调整为更轻的浅色 editorial 内容页：

- 首屏使用左右排版：左侧标题、文案和操作，右侧真实内容工作台图片。
- 公告条、分类入口、文章区、项目区、实验记录区使用细分隔线、留白和列表节奏。
- 保持现有数据结构、组件边界和静态内容来源，不新增接口或业务功能。

## 验收标准

- Hero 标题是首屏最高视觉权重，图片作为内容气质补充。
- 文章区包含“近期文章”标题、精选文章横排卡片和轻量文章列表。
- 右侧内容对象保持辅助信息权重，不压过文章主列。
- 项目区使用编号列表、状态标签和章节标签，不做卡片墙。
- 实验记录区使用时间线，并保留“今日维护”面板和后台入口。
- 375px 移动端不应出现横向溢出或文字重叠。
