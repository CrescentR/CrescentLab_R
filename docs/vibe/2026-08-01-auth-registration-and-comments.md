# 登录、注册与评论权限闭环

## 目标

用真实账号体系替换首页演示身份，并建立访客、普通用户、管理员三档权限。账号密码作为当前登录方式，后续 OAuth 与第三方登录在独立需求中接入。

## 权限矩阵

| 能力 | 访客 | 普通用户 | 管理员 |
| --- | --- | --- | --- |
| 阅读公开内容与已通过评论 | 是 | 是 | 是 |
| 注册、登录 | 是 | 是 | 是 |
| 提交文章评论 | 否 | 是 | 是 |
| 访问 `/admin/**` 页面 | 否 | 否 | 是 |
| 调用 `/api/admin/**` 接口 | 否 | 否 | 是 |

## 验收标准

- 首页未登录时显示真实登录、注册链接，不再出现演示身份选择。
- 用户可使用用户名、昵称和至少 8 位密码注册，注册后直接获得普通用户登录态。
- 登录接口允许有效的普通用户与管理员账号登录，并返回由数据库身份决定的角色。
- 登录后的普通用户看到自己的昵称和退出入口；管理员额外看到后台入口。
- 普通用户直接访问 `/admin/**` 会被送回首页，访客会被送到登录页。
- `/api/admin/**` 继续由后端同时校验有效 JWT 与管理员角色。
- 登录用户可在允许评论的文章下提交评论；新评论为待审核状态。
- 公开评论列表只返回已审核通过且未删除的评论。
