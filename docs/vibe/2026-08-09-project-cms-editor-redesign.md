# 项目 CMS 编辑发布页重构

## 目标

将后台项目编辑页重构为 SaaS/CMS 风格的项目发布工作区。复用现有项目资料、富文本介绍、静态站点产物、版本预览和发布接口，不新增后端字段或发布机制。

## 范围

- 项目编辑页改为“项目概览 / 展示内容 / 部署版本”三模块工作区。
- 顶部统一展示项目身份、当前状态、保存状态以及保存和发布操作。
- 项目概览集中编辑名称、标语、简介、slug、封面、仓库、演示地址和技术栈。
- 展示内容继续使用现有 TipTap 编辑器维护项目介绍正文。
- 部署版本集中展示线上状态、静态站点上传、不可变版本历史、预览和发布/回滚操作。
- 保留现有项目列表、新建、编辑和删除行为。

## 不在范围

- 不新增项目字段、权限、环境、域名或部署供应商配置。
- 不修改项目及产物 API。
- 不调整公开项目页面。

## 验收标准

- 新建和编辑项目均可进入统一的项目 CMS 工作区。
- 三个模块职责明确，项目资料与发布产物不混在文章式侧栏中。
- 保存保留项目当前状态，发布后普通保存不会把项目改回草稿。
- 未保存项目不能上传产物，并有明确说明。
- 已有产物可预览、发布或回滚，当前线上版本清晰可见。
- 桌面端形成侧栏与主画布布局，窄屏可正常纵向使用。
- TypeScript、相关 ESLint 和生产构建通过。
