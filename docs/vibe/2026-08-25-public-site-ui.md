## 1. 内容模型与阅读路径

公开站只有三类内容对象。它们共享导航、纸面颜色、月牙标识和字体族，但字段、扫描方式和详情节奏不同。

### 1.1 项目 Project

已经形成稳定名称、明确用途和可维护边界的成果。

| 字段 | 用途 |
| --- | --- |
| 名称、副标题、短描述 | 扫描与定位 |
| 分类、技术栈 | 技术组成的压缩表达 |
| 状态 `live` / `building` / `research` | 中文+英文+颜色同时出现 |
| 更新时间 | 新鲜度 |
| 封面或纯排版视觉 | 可选；无图时用 `PRJ—0N` 排版，禁止灰框 |
| Demo、仓库 | 仅在有效时出现 |
| 背景、能力、技术组成、进度、后续 | 详情页展开 |

路径：导航「项目」→ 筛选扫描 → 精选/普通卡片 → **独立详情页** → Demo/仓库/返回列表。

详情不用全屏营销层。从卡片点进独立页，保留顶栏当前位置，内容区提供「返回项目列表」。

### 1.2 笔记 Note

整理完成、可独立阅读和长期引用的正式文章。

| 字段 | 用途 |
| --- | --- |
| 标题、摘要 | 发现与引用 |
| 封面 | 可选 |
| 发布日期、字数、时长、阅读量 | 元信息 |
| 精选 / 置顶 | 层级，不是装饰 |
| 正文、目录、评论 | 沉浸阅读 |

路径：导航「笔记」→ 搜索/全部·精选/杂志·列表 → 精选文或普通文 → 窄列阅读（目录+工具）→ 评论 → 返回。

### 1.3 观测记录 Observatory

实验、失败、问题与验证后的认识。不是正式文章，也不是监控后台。

| 字段 | 用途 |
| --- | --- |
| `OBS—001` | 档案编号，JetBrains Mono |
| 标题 | 索引扫描 |
| Question / Observation / Conclusion / Next | 推理链 |
| 类型：片段、失败、想法、工具想法、技术债 | 档案分类 |
| 状态：进行中、已解决、已放弃 | 文字+颜色 |
| 标签、精选、创建/更新时间 | 过滤 |
| 相关项目/笔记 | 有数据才出现 |

路径：导航「实验观测台」→ 索引栏快速扫多条 → 卡片露出问题或结论 → 详情按 问题→背景→观察→结论→下一步 → 上一条/下一条。

## 2. 统一品牌，三种气质

| | 项目 | 笔记 | 观测台 |
| --- | --- | --- | --- |
| 气质 | 成果目录 / 制品 | 编辑式杂志 / 长读 | 研究索引 / 实验档案 |
| 标题字体 | 衬线页题 + 无衬线卡片 | 衬线贯穿 | 等宽编号 + 衬线标题 |
| 网格 | 不对称但可扫描，精选更大 | 精选文 + 杂志马赛克 / 紧凑列表 | 左索引 + 右多条结构卡 |
| 强调色 | 苔绿=live，雾蓝=building，灰紫=research | 苔绿=当前章节/链接，琥珀=精选 | 雾蓝=问题，琥珀=观察，苔绿=结论，陶土=失败类型 |
| 禁止 | 广告 Banner、后台统计卡 | 牺牲标题扫描的纯装饰杂志 | 假曲线、服务器指标、单张巨大卡片 |

共享：顶栏、月牙、`#F6F5EF` 纸面、细边框、8–16px 圆角、克制阴影、Lucide 线性图标。

## 3. 全局规范

实现时优先绑定 `frontend/src/app/globals.css` 已有令牌。

### 3.1 颜色

强调色只用于状态、当前项、链接和关键数据。

| Token | Hex | 用途 |
| --- | --- | --- |
| `--background` | `#F6F5EF` | 页面 |
| `--surface` | `#FFFEFA` | 主表面、顶栏 |
| `--surface-raised` | `#F8F8F3` | 抬升、代码块底 |
| `--surface-field` | `#F0F1EB` | 内凹、芯片默认底 |
| `--text-strong` | `#1C2821` | 标题 |
| `--text` | `#46534B` | 正文 |
| `--muted` | `#637068` | 辅助 |
| `--muted-low` | `#8B958D` | 元信息 |
| `--border` | `#DCDCD1` | 细边框 |
| `--teal` | `#397864` | 苔绿：当前、链接、live、结论 |
| `--blue` | `#52758F` | 雾蓝：building、问题 |
| `--violet` | `#7A6F92` | 研究中、Agent |
| `--amber` | `#8C713B` | 进行中、精选、观察 |
| `--coral` | `#A96350` | 失败类型、警告 |
| `--success` | `#43805C` | 已解决 |
| `--danger` | `#B3524A` | 错误 |

软底：对应色 10–12% 透明，作 pill 与当前导航底。

对比：正文与页面、强文字与表面需达到正文可读对比。链接不只靠颜色，需下划线或字重变化。

### 3.2 字体

| 角色 | 设计指定 | Figma/落地 |
| --- | --- | --- |
| 中文 UI | HarmonyOS Sans SC 或 Noto Sans SC | `Noto Sans SC` 14–16/20–26 |
| 英文与数字 UI | Helvetica Neue | `Inter` Medium，11–12px，字距 +0.8px |
| 页题与长文 | Noto Serif SC + Newsreader | 页题 40/52，正文 18/32 |
| 诗词/随笔/特殊引用 | LXGW WenKai Screen | 仅作者标记句；Figma 用 `LXGW WenKai TC` |
| 编号、实验 ID、代码 | JetBrains Mono | 12–13px |

霞鹜文楷**不得**成为站点或技术正文默认字体。引用块：字号 20/34、额外留白、1–2px 苔绿左边线，禁止花饰。

### 3.3 间距、圆角、阴影、动效

- 间距基数 4：8 / 12 / 16 / 24 / 32 / 48 / 64
- 桌面左右沟槽 120，内容最大宽 1120–1200
- 移动端左右 20，主操作高度 ≥ 44
- 圆角：标签 4、按钮/芯片 8、卡片 12、精选容器 16。禁止大胶囊
- 阴影：`tight` 默认卡，`hover` 悬停，`soft` 弹层。不同时叠加强色、粗边、重阴影
- 动效只服务进入、展开、切换、层级；`prefers-reduced-motion` 时时长为 0
- 主内容禁止横向滚动；筛选芯片在 390 上可以单独横滑

页面氛围：极轻纸纹 + 页角苔绿/雾蓝光晕 + 低对比实验室网格，不得压过文字。

## 4. 全局导航

桌面顶栏 64px，`--surface`，底边 `--border-soft`。

左：月牙线标 + `CRESCENT LAB`  
中：首页 · 构建中 · 实验观测台 · 项目 · 笔记 · 关于  
右：登录 / 用户，次级，不要做成主按钮

当前项：苔绿字 + 浅苔绿底，圆角 8。悬停：field 底。焦点：2px 苔绿描边 + 3px 浅苔绿光晕。

详情页仍显示完整导航；返回入口放在内容区第一行，不替换顶栏。

移动端：品牌 + 当前栏目名；主导航收入菜单。详情页：返回栏目名 + 当前标题截断。

## 5. 核心组件与状态

组件源在 Figma `00 Foundations & Components`：Button、Status、Tag、Nav Item、Site Header。

### 5.1 Button

| Variant | Default | Hover | Focus |
| --- | --- | --- | --- |
| Primary | 苔绿底、反白字 | 墨色底 | 苔绿底 + Focus ring |
| Ghost | 表面 + 细边 | field 底、阴影 tight→hover | 苔绿边 + ring |
| Text | 无底、苔绿字 | 浅苔绿底 | ring |

### 5.2 Status

必须「色点 + 中文（项目可加英文）」。

- 已上线 live → 苔绿
- 构建中 building → 雾蓝
- 研究中 research → 灰紫
- 进行中 → 琥珀
- 已解决 → 成功绿
- 已放弃 → 辅助灰

### 5.3 Tag / Filter

等宽 11px。默认 field 底；选中墨底反白或苔绿软底。焦点与按钮相同 ring。

### 5.4 目录 TOC

默认：辅助色。当前：苔绿 + 左侧 2px 条。悬停：正文色。

### 5.5 代码块

raised 底、1px 边、12px 圆角、JetBrains Mono 13/22、右上角复制。不要暗色终端皮肤。

### 5.6 文楷引用

仅 `wenkai-text` 标记句。左边线、额外上下留白、字距略松。

### 5.7 项目卡

精选：更大、可含排版视觉 + 主操作。普通：名称、副标题、短描述、分类、状态、技术栈、更新、详情；有效时 Demo/仓库。无图用 `PRJ—0N` + 一句定位，禁止空白占位框。不要做成完全同构卡片。

### 5.8 笔记卡

精选一篇更高。普通：标题、摘要、可选封面、日期、时长、阅读量、精选/置顶。杂志网格与紧凑列表共用字段，列表更强调标题扫描。

### 5.9 观测卡

至少露出编号、标题、类型、状态，以及问题 / 核心观察 / 结论之一。Q/O/C 用左边线区分，不要四张同构小卡。列表必须同时可见多条。

### 5.10 加载 / 空 / 错误

| 状态 | 表现 |
| --- | --- |
| 加载 | 纸面骨架或一行「正在读取…」，保留页头与筛选结构 |
| 空 | 衬线短句说明空的原因，无插画、无虚线框 |
| 错误 | 明确失败句 + 「重试」。失败时不回退 mock、不假装为空 |
| 搜索无结果 | 「没有匹配「…」」+ 清除筛选 |

## 6. 页面布局与交互

视觉稿以图为准；若图中出现英文残留、统计大卡、装饰图或浏览器外壳，**以本节为准**。

### 6.1 项目总览 `desktop-01` / `mobile-01`

- 页题「项目」+ 一句说明，不要整屏 Hero
- 摘要用一行排版：`6 个项目 · 3 已上线 · 2 构建中 · 1 研究中`，不要后台统计卡
- 筛选：全部 / 已上线 / 构建中 / 研究中
- 桌面：精选占约 2/3，侧卡 1/3，下一行 3 张不同权重
- 移动：竖向堆叠；筛选芯片可横滑；主按钮全宽 44px
- 悬停卡片：边框略加深 + hover 阴影，结构不变

### 6.2 项目详情 `desktop-02` / `mobile-02`

独立页。返回列表。名称、定位、状态。编号段落：01 背景 02 能力 03 技术 04 进度 05 后续。成果媒体用真实界面或克制排版，可缺省。Demo / 仓库 / 复制链接。

移动：底栏固定「打开 Demo | 仓库 | 分享」；章节纵向排列，不要右侧操作柱。

### 6.3 笔记列表 `desktop-03` / `mobile-03`

- 页题「笔记」+ 说明
- 统计：篇数、累计阅读、总时长、精选数，做成元信息条而不是四张 KPI 卡
- 搜索标题/摘要；全部/精选；杂志/列表
- 一篇精选更高；其余可扫描；加载更多
- 空 / 无结果 / 失败见 5.10

### 6.4 笔记详情 `desktop-04` / `mobile-04`

返回笔记。眉题、标题、摘要、时间/字数/时长/阅读量。可选封面，非 16:9 不裁切。正文列约 640–680。桌面左目录（标识当前章）+ 阅读进度；右或顶：字号、复制、分享、收藏。正文样式覆盖标题、段落、列表、表、图、代码、引用。文楷句仅作者标记。文末统计、评论、返回。

移动：取消固定侧栏。目录与 Aa 收入底部或顶栏轻量入口，用 sheet 打开。进度为顶栏细线。

### 6.5 观测台列表 `desktop-05` / `mobile-05`

研究索引。左索引（编号+标题+状态，当前苔绿条），右多张结构卡。状态/类型/标签筛选 + 标题搜索。不要单张巨大卡片占满舞台，不要仪表盘曲线。

移动：取消左右分栏，改为可扫的档案行；筛选芯片换行或横滑。

### 6.6 观测详情 `desktop-06` / `mobile-06`

返回观测台。OBS 编号、标题、类型、状态、标签、时间。推理顺序固定：问题 → 背景/正文 → 观察 → 结论 → 下一步。四段靠编号、字号、左边线区分。已解决：结论区苔绿提示。已放弃：辅助灰提示「已停止跟进」+ 原因仍可读。上一条/下一条。相关项目/笔记有数据再显示。

移动：五段纵向；顶条显示链上当前位置；底或顶提供上一条/下一条。

## 7. 无障碍与动效

- 焦点态对键盘可见，不要只用 hover
- 状态不只靠颜色
- 正文/辅助文字满足对比
- 动效 180–320ms，`prefers-reduced-motion` 关闭位移
- 触控目标移动端 ≥ 44px
