# GSAP 实验观测台

## 目标

将首页现有的静态实验列表改造成滚动驱动的“实验观测台”，复用现有实验数据和暗色实验室视觉变量，通过 GSAP 建立清晰的内容切换节奏，同时保持移动端与减少动态效果场景下的直接阅读体验。

## 范围

- 保留首页现有 `#experiments` 锚点、三条 `labExperiments` 数据和页面内容顺序。
- 桌面端使用一个顶层 GSAP Timeline 与 ScrollTrigger，固定实验区并随滚动切换三条记录。
- 左侧展示实验索引与进度，右侧展示当前记录、标签、状态和抽象观测图形。
- 动画只使用 transform 与 `autoAlpha`，不动画宽高、定位或间距。
- React 侧使用 `useGSAP` 和组件根节点 scope，并在卸载或媒体条件变化时清理动画。
- 980px 以下取消固定和 scrub，按顺序展示三张实验卡片。
- `prefers-reduced-motion: reduce` 下不创建滚动动画，全部内容静态呈现。
- 不新增路由、接口、实验数据、平滑滚动库或 GSAP 高级插件。

## 验收 Checklist

- [x] 桌面端实验区固定后可随滚动依次切换三条现有实验记录。
- [x] ScrollTrigger 只挂在顶层 Timeline，子动画没有独立 ScrollTrigger。
- [x] 左侧索引、进度轨、右侧内容与观测图形保持同步。
- [x] 移动端按顺序展示完整内容，不固定页面且不隐藏标签。
- [x] 减少动态效果时三条内容全部可见且无位移动画。
- [x] GSAP 选择器限制在实验组件根节点内，组件卸载后无残留动画。
- [x] 保留现有首页、字号和 WebGL 未提交改动。
- [x] `pnpm typecheck`、`pnpm lint` 和 `pnpm build` 通过。
- [x] Docker 中启动页面并完成桌面、移动端和减少动态效果浏览器验证。

## 验证结果

- 前端类型检查、Lint 与生产构建均通过。
- 等价前端 Docker 阶段成功构建并启动，页面返回 200；真实浏览器完成桌面端、移动端和减少动态效果模式验证。
- 项目完整 Docker 构建仍受当前后端 `internal/platform/http` 导入循环阻断；该问题不在本次前端改动范围内。
