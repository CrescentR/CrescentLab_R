# 观测台、构建中与云端媒体

日期：2026-08-23

## 目标

按内容平台设计理念把「实验观测台」和「正在构建」做成真实内容对象：观测台记录问题、观察和结论，构建中记录当前投入与进展；媒体文件只写入已配置的云存储策略，不再落本地磁盘。

## 范围

- 观测台：结构化观察字段、公开/精选、公开读取接口、前台真实数据、后台低摩擦表单。
- 构建中：新增 `builds` 表与模块，替换 localStorage 雏形；公开读取；前台真实数据。
- 媒体：存储策略类型去掉 local；上传继续走默认云策略。

## 不在范围

- 首页聚合接口 `/api/home`
- 观测详情独立路由、构建详情独立路由
- 观测台与构建/项目的关联外键
- 版本历史
- 虚构 QuickBox 等内容

## 验收标准

- 观测台后台可维护标题、类型、状态、问题、观察、结论、下一步、标签、是否公开、是否精选。
- 公开 `GET /api/observatory` 只返回公开记录；私有记录不出现。
- `/experiments` 使用真实公开数据；无数据时展示空状态，不回退 mock。
- 构建中后台可维护 PRD 字段并发布；公开 `GET /api/builds` 只返回已发布项。
- `/building` 使用真实已发布数据；无数据时展示空状态，不回退 mock。
- 存储策略不能创建 `local` 类型；媒体上传写入当前默认云策略。
