# TipTap 颜色与代码块增强

日期：2026-08-01

## 目标

完善文章编辑器中的文字/背景颜色与代码体验，对齐更接近写作工具的交互。

## 需求细节

1. 文字颜色、背景颜色：提供更丰富的预设色盘，支持系统色盘与十六进制输入。
2. 「清除颜色」需真正移除当前选区上的颜色/背景色。
3. 行内代码样式需明显可辨（边框、底色、字色）。
4. 代码块升级为窗口式组件：可选语言、复制、字号/缩进/自动换行/行号。

## 验收标准

- [x] 颜色菜单含色盘 + hex，应用后选区样式立即变化
- [x] 清除颜色后选区不再保留 color / background-color
- [x] 空光标落在已着色文本上时，清除仍能生效（自动扩到当前文本节点）
- [x] 高亮使用 `<mark>`，不再与 `textStyle.backgroundColor` 双重叠加
- [x] 行内 `code` 在编辑器中对比清晰
- [x] 插入代码块后可见 mac 风格标题栏、语言下拉与设置项
