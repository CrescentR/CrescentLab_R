# 笔记详情页独立数字刊物改版

日期：2026-08-31

## 目标

不再复用公开站的暖白、墨绿、圆角卡片和克制单列模板，把文章详情做成一套独立的高对比数字刊物。保留真实文章数据、富文本和互动能力，但从布局、色彩、字体、导航到评论区全部重新设计。

## 视觉方向

- 深色全屏封面故事，超大斜体标题与错位封面图建立首屏冲击力
- 荧光黄、信号橙与钴蓝作为独立于公共站的高对比色
- 正文进入纸张式舞台，阅读工具表现为黑色控制台
- 章节目录使用蓝色索引板，正文标题、引用、代码和图片采用强边框与错位阴影
- 相关文章使用横向大索引，评论区使用整块钴蓝讨论场
- 文章路由的顶部导航和页脚同步进入刊物模式

## 验收标准

- [x] 与原三栏杂志和暖白单列方案存在明显视觉差异
- [x] 标题、封面、真实元信息在桌面和移动首屏均清楚可见
- [x] 无摘要、无目录、无相关文章时不渲染空结构
- [x] 字号、喜欢、收藏、分享、评论和代码复制保持可用
- [x] 正文覆盖标题、段落、列表、引用、代码、图片和表格
- [x] 移动端无页面横向溢出，主要交互目标不小于 44px
- [x] 尊重 `prefers-reduced-motion`
