# 浅色主题 UI 舒适度优化

## 目标

在不改变公开站点信息结构和交互逻辑的前提下，延续现有暖白、墨绿、苔绿的浅色视觉方向，改善页面层级、对比度和长时间阅读舒适度。

## 范围

- 统一公开站点与全局浅色主题令牌，避免两套颜色定义继续偏移。
- 调整背景、卡片、抬升表面、边框、正文和辅助文字的层级。
- 为导航、按钮、卡片和键盘焦点补充克制且一致的状态表达。
- 保留现有路由、组件结构、内容、动效和响应式布局。

## 验收标准

- 六个公开页面在桌面视口下具有一致且可辨认的页面、卡片和抬升表面层级。
- 首页在移动视口下无横向溢出，主要操作和核心视觉保持清晰。
- 颜色优先来自 `frontend/src/app/globals.css`，公开站点不再复制同一套基础色值。
- `prefers-reduced-motion`、键盘焦点和既有页面交互不退化。
- 前端类型检查、Lint、生产构建及真实浏览器截图验证通过。
