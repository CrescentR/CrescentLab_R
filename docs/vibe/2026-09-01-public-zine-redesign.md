# 公开站数字刊物视觉统一改版

日期：2026-09-01

## 范围

统一改造公开内容站：`/`、`/updates`、`/projects`、`/notes`、`/about`、`/articles/{slug}`，以及共用导航和页脚。旧的 `/building` 与 `/experiments` 入口统一跳转到 `/updates`。

不包含：`/admin/*`、`/login`、`/register`。

## 目标

把文章详情已采用的独立数字刊物视觉扩展到整个公开站。取消暖白、墨绿、圆角卡片、玻璃拟态和克制产品站模板，统一使用黑色基底、荧光黄、信号橙、钴蓝、超大刊物标题、硬边框、错位阴影与网格背景，同时保留每个内容模块不同的信息结构。

公开站不再使用“实验室”“正在构建”“实验观测台”等概念。站点名称统一为 `Crescent Index`，原“正在构建”和“实验观测台”归并到“动态”，分别以“近期进展”和“过程记录”呈现；底层数据接口与后台维护入口保持不变。

## 验收标准

- [x] 公开站导航、页脚和各页面使用同一高对比视觉语言
- [x] 首页不再使用月球轨道视觉，建立新的站点第一印象
- [x] 动态、项目、笔记和关于页具有不同布局，不是同一模板复制
- [x] 公开导航不再出现实验室相关概念，近期进展与过程记录统一归入动态页
- [x] 现有真实数据接口、筛选、视图切换、弹窗和拖拽交互保持可用
- [x] 文章详情视觉和其他公开页面自然衔接
- [x] 桌面和移动端无页面横向溢出，主要交互目标不小于 44px
- [x] 尊重 `prefers-reduced-motion`
- [x] 更新设计规范与 changelog
