# 公开站数字刊物视觉统一改版

日期：2026-09-01

## 范围

统一改造公开内容站：`/`、`/building`、`/experiments`、`/projects`、`/notes`、`/about`、`/articles/{slug}`，以及共用导航和页脚。

不包含：`/admin/*`、`/login`、`/register`。

## 目标

把文章详情已采用的独立数字刊物视觉扩展到整个公开站。取消暖白、墨绿、圆角卡片、玻璃拟态和克制产品站模板，统一使用黑色基底、荧光黄、信号橙、钴蓝、超大刊物标题、硬边框、错位阴影与网格背景，同时保留每个内容模块不同的信息结构。

## 验收标准

- [ ] 公开站导航、页脚和各页面使用同一高对比视觉语言
- [ ] 首页不再使用月球轨道视觉，建立新的站点第一印象
- [ ] 构建中、观测台、项目、笔记和关于页具有不同布局，不是同一模板复制
- [ ] 现有真实数据接口、筛选、视图切换、弹窗和拖拽交互保持可用
- [ ] 文章详情视觉和其他公开页面自然衔接
- [ ] 桌面和移动端无页面横向溢出，主要交互目标不小于 44px
- [ ] 尊重 `prefers-reduced-motion`
- [ ] 更新设计规范与 changelog
